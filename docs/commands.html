Commands

All slash commands available in Insomniacs Bot. Type / in any channel to get started.

✓ Available Implemented Planned On the roadmap

General

/ping ✓ Available

Check bot status and latency. Shows round-trip and WebSocket ping.

/ping

Account Management · Phase 2

/link Planned

Link your Discord account to a FACEIT nickname. The bot verifies it's a CS2 account and stores the stable player ID.

/link faceit:YourFaceitNickname
/unlink Planned

Remove your FACEIT account link. Stored match history is retained.

/unlink
/linkstatus Planned

View your currently linked FACEIT account and last sync time.

/linkstatus /linkstatus user:@Adam

Player Statistics · Phase 4

/stats Planned

Full statistics embed — ELO, level, K/D, ADR, headshot %, win rate, streaks, recent form, favourite map. Buttons to jump to Recent, Maps, and Records.

/stats /stats user:@Adam /stats user:@Adam period:week /stats user:@Adam period:month /stats user:@Adam period:all
/recent Planned

Last 5–10 matches with map, score, W/L, kills, deaths, ADR, and ELO change.

/recent /recent user:@Adam
/form Planned

Performance summary over a recent window — wins, losses, K/D, ADR, ELO movement, best and worst match, current streak.

/form /form user:@Adam /form user:@Adam matches:20

Group Statistics · Phase 5

/leaderboard Planned

The Insomniacs leaderboard. Choose a category via select menu — ELO, K/D, win rate, ADR, total kills, longest win streak, most 30-bombs, biggest ELO session, and more.

/leaderboard
/compare Planned

Head-to-head comparison between two linked players, including stats for matches where both were present.

/compare player1:@Adam player2:@Dave

Maps · Phase 5

/maps Planned

Map breakdown — matches played, wins, losses, and win rate per map. Group view or individual player view.

/maps /maps user:@Adam
/mapstats Planned

Detailed statistics for a specific map — games, win rate, K/D, ADR, highest kill game, best performer.

/mapstats map:Mirage /mapstats map:Ancient user:@Adam

Records & History · Phase 6

/records Planned

The Insomniacs all-time record book — highest kills, best ADR, longest streaks, most 30-bombs, biggest ELO sessions. Updated silently, never announced.

/records
/session Planned

Stats for the most recent play session — games, W/L, ELO change, K/D, ADR, best and worst game, maps played.

/session /session user:@Adam

Chemistry · Phase 7

/chemistry Planned

Duo statistics — games together, win rate, K/D, ADR. Shows best teammate, worst teammate, most-played-with, highest and lowest win-rate duo. Requires a minimum match sample (default: 10).

/chemistry /chemistry user:@Adam

Achievements · Phase 8

/achievements Planned

View earned achievements — calculated silently from match data, never announced. Examples: Thirty Bomb, The Hard Carry, On Fire, Tilt Queue, Go To Bed, The Insomniac.

/achievements /achievements user:@Adam

Quotes · Phase 9

/quote Planned

Retrieve a random saved quote, optionally filtered to a specific person.

/quote /quote user:@Adam /quote add user:@Adam text:"..."
Save Quote Planned

Right-click context menu command. Right-click any message → Apps → Save Quote. Stores author, text, channel, date, and who saved it.

Right-click message → Apps → Save Quote
Pull-based only

None of these commands post automatically. Every response requires a user to actively ask for it.
